# Music Shop Management System

## Описание проекта

**Music Shop Management System** — это приложение для управления ассортиментом музыкального магазина. Оно позволяет добавлять, отображать и управлять различными товарами, такими как гитары (классические, акустические, электрические), ремни, медиаторы и струны. Каждый товар имеет свои уникальные параметры, которые отображаются на панелях в пользовательском интерфейсе.

Проект реализован на языке C# с использованием Windows Forms для создания графического интерфейса.
