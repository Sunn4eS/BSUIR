Can stored functions change data in databases?
No for MS SQL Server, yes for MySQL and Oracle.

Can stored functions change database objects?
Yes for Oracle (requires PL/SQL block), no for MySQL and MS SQL Server.

What is the difference between a stored procedure and a stored function?
Stored procedure has its own call and results processing syntax, stored function allows built-in integration in any SQL-query.
Stored procedure may produce transactions, stored function may not.

What is the difference between a stored procedure and a stored function?
Stored procedure has rich exceptions handling capabilities, stored function has limited exceptions handling capabilities (none in some DBMSes).
Stored procedure may call other stored procedures and stored functions, stored function may call other stored functions only.

Can we execute a dynamic query from within a stored procedure?
Yes, in all DBMSes.

Can we access information about database objects from within a stored procedure?
Yes, in all DBMSes.

Using stored procedures has the following cons…
Testing and/or debugging may become more difficult.
There may be security issues (in case of wrong permissions settings).
